Project Atlântida

em desenvolvimento · privado

Automação pessoal em Node.js para centralizar informações acadêmicas da plataforma FIAP EAD, usando web scraping.

sem captura de tela disponível no momento — projeto ainda em construção

$ cat objetivo.txt

Nasceu de uma vontade dupla: automatizar tarefas repetitivas da plataforma de estudos da FIAP e, ao mesmo tempo, praticar programação, automação e sistemas web na prática. A ideia central é fazer login automaticamente, coletar materiais e informações acadêmicas, e disponibilizar isso de forma organizada — sem precisar entrar na plataforma toda hora pra conferir o que mudou.

$ cat arquitetura.txt

O projeto é modular, com responsabilidades separadas:

project-atlantida/
├── scraper/        → login, coleta de materiais, tarefas, provas
├── data/           → data.json (estado do mês atual) + histórico mensal
├── discord-bot/     → interface de consulta (planejado)
└── ia/              → módulo de interpretação autônoma (planejado)

$ cat funcionalidades.txt

Já implementado:

  • Login automatizado na plataforma FIAP EAD
  • Separação das funções do scraper em arquivos (login, materiais, JSON)
  • Leitura e escrita de dados em JSON
  • Acesso direto à página de materiais
  • Coleta dos nomes dos materiais e do percentual de progresso
  • Filtro de elementos duplicados entre os layouts desktop e mobile
